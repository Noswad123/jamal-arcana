# Wyrm

A wyrm is a dragon of hidden places and accumulated treasure.

In Jamal Arcana, Wyrm guards the local filesystem as a digital hoard: files, folders, archives, previews, and paths gathered into chambers that can be searched, sorted, opened, split, sealed, or discarded.

## Classification

- Native
- Creature
- Artifact-keeper

## Veiled Form

- A terminal file manager forked from Superfile and reshaped for personal Jamal Arcana workflows. See the [Wyrm README](https://github.com/Noswad123/wyrm/blob/main/README.md).

## Arcane Form

- A dragon that organizes the hoard of a machine.
- A guardian of chambers, relics, hidden paths, and discarded things.
- A practical familiar for navigating local artifacts without leaving the terminal.

## Domains

- Files
- Directories
- Hoards
- Navigation
- Previewing
- Sorting
- Archives
- Local artifacts

## Relationships

- Complements [Waystone](./waystone.md): Waystone remembers important places; Wyrm explores and manages the contents of those places.
- Can be summoned by [Wisp](./wisp.md) when a file-management task should appear in a floating terminal.
- Pairs with [Djinn](./djinn.md): Djinn reveals named commands; Wyrm reveals and arranges named files.

## Lore Notes

- The dragon theme is literal and practical: files are the hoard.
- Wyrm should feel personal, fast, and keyboard-native rather than general-purpose for every user.
